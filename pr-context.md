# PR Context — Upgrade @quasar/app-vite 1.x → 2.6.2 & @quasar/extras 1.x → 2.0.3

## Objective
Upgrade the frontend build tooling to `@quasar/app-vite@2.6.2` and `@quasar/extras@2.0.3` with no regressions or incompatibilities. Stays on **quasar v2** (`^2.23.5`) — no forced quasar major.

## Changes
- `frontend/package.json`: `@quasar/app-vite` `^1.7.1` → `^2.6.2`, `@quasar/extras` `^1.17.0` → `^2.0.3`.
- `frontend/quasar.config.js` → `frontend/quasar.config.cjs`: kept project **CommonJS** (avoids `"type": "module"` cascade that would break `.eslintrc.js`/`postcss.config.js`). Removed the dropped `eslint` config block (linting still runs via `pnpm run lint`). Bumped `build.target.node` `node16` → `node22` (app-vite 2.6.2 requires Node 22+).
- `frontend/tsconfig.json`: no longer extends removed `@quasar/app-vite/tsconfig-preset`; now extends auto-generated `.quasar/tsconfig.json` (regenerated via `quasar prepare`).
- Deleted `frontend/src/quasar.d.ts` and `frontend/src/shims-vue.d.ts` — auto-generated by app-vite 2.x.
- `.github/workflows/ci-pr.yml`: Node 20.x → 22.x (required by app-vite 2.6.2).

## Deliberately kept (low-risk)
- `require('dotenv').config()` stays in config (works fine in `.cjs`).
- `quasar/wrappers` imports stay (deprecated but fully functional in v2).
- `@quasar/cli` untouched.

## Verification (all green)
- `pnpm install` — clean, no peer conflicts.
- `pnpm run lint` — 0 errors (4 known pre-existing `v-html` warnings).
- `pnpm run prettier` — clean.
- `quasar build` — Build succeeded (SPA, vite 8.2.1).
- `quasar dev` smoke test — HTTP 200.
- E2E (mock backend, `USE_MOCK_BACKEND=true`): `/articles`, `/articles/Sample_Article`, `/account`, `/shares/test-token` all render correctly; `/auth` redirects to `/articles` (auth guard works). No blank screens, no broken imports/icons.

## Caveats / flags for review
- **Node 22+ is now mandatory** for the frontend (app-vite 2.6.2 engines). Local tooling and CI updated accordingly.
- No DB/data-model changes — this is a pure frontend build-tooling upgrade.
